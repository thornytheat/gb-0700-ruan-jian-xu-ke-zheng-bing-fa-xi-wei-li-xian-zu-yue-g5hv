# 席位定义

lease_id、user保持字符串。CAD-Pro、cad归一为CAD。kind取online、offline、heartbeat、release、capacity、coverage、gap。coverage声明区间内网关日志完整，gap声明区间内日志断档。start/end必须带时区并转换UTC。seats为正整数；capacity记录表示采购生效区间的席位上限。

在线租约可由同租约同版本release提前结束；离线授权一直占用至原到期时刻，即使收到release仍保留。心跳不建立租约。租约采用最高版本；同版多条实体租约冲突隔离。采购区间可重叠，最高version优先，同最高版不同数量返回CAPACITY_CONFLICT。

并发使用半开区间[a,b)，结束同刻开始不重叠。采购边界必须切分并发段。超用责任按租约开始时间倒序、再按编号倒序分配，分配席位严格等于超用数量。超用席位小时为超用数量×秒数/3600，Decimal计算。此工具只核验约定席位数，不含厂商复杂许可证条款。

租约ID在产品内唯一；不同产品允许相同租约号。线上租约在start同刻release得到零时占用，离线仍保留原到期。

## 断档与补证

没有 gap 记录时视为日志完整，超用全部记为已证实。gap 覆盖到的超用窗口记为待补证：尚未证明违规，允许按当天结论发布但不盖章。更高版本且完整包住该 gap 的 coverage 记录视为补证完成，撤销该断档，相关窗口重算为已证实。并发段与超用段都在 gap / coverage 端点切分，保证同一段内证据状态一致。采购对照口径不变：仍按超用席位×秒数/3600 汇总。

## 发布链

同一批次的补传形成版本链：root_id 标识批次，parent_id 标识上一发布，publish_no 为发布序号。合并输入按行去重，同批补传重试得到相同输入并复用已有版本，不重复发布。版本写入在单事务内完成，失败回滚并保留旧版完整结果。每个发布版本的结论、隔离记录与证据CSV保持不变，可随时回查。
